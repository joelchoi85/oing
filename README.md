# 오잉? (oing)

저작권이 끝난 고전 명화로 하는 **직소 퍼즐 · 숨은 그림 찾기 · 다른 그림 찾기** 모바일 게임. 혼자(오프라인)도, 함께(협동)도 할 수 있다. 화랑에 온 듯한 르네상스·바로크 분위기.

## 기획
- [개요](기획/개요.md) — 한 줄, 누구를 위한 게임인가, 핵심 결정
- [게임 모드](기획/게임%20모드.md) — 직소 / 숨은 그림 / 다른 그림, 혼자·협동, 리더보드
- [실물 퍼즐 표현](기획/실물%20퍼즐%20표현.md) — 조각 모양, 두께, 옆면, 음영, 테이블
- [UI 스타일](기획/UI%20스타일.md) — 르네상스·바로크 화랑
