# UI 스타일 — 르네상스·바로크 화랑

## 비유
게임 전체가 **오래된 미술관**이다.
- 그림 고르기 = 액자 아래 **명판**(작가·제목·연도·소장처·라이선스).
- 다 맞춘 그림 = "나의 화랑"에 걸린다. 리더보드 = 방명록(깃펜 손글씨 느낌 이름).

## 재료와 색
**오래된 그림처럼 빛바랜 색**: 채도 대략 0.4 이하, 명암 차도 부드럽게. 명화보다 UI 가 튀면 안 된다. 코드는 `scripts/ui_palette.gd` (`UiPalette`) 하나에서만 색을 꺼내 쓴다.

| 이름 | 쓰는 곳 | 색 |
|---|---|---|
| 금박 | 액자, 버튼 테두리, 돋보기 테 | #A88F61 (밝은 쪽 #D4C299, 그늘 #5C4A33) |
| 흑단·호두 | 손잡이, 어두운 장식 | #2B211C / #573F30 |
| 펠트 | 탁자 | #29362E (판 자리 #212B26) |
| 옥스블러드 벨벳 | 패널 바탕, 커튼 (아껴서) | #663630 |
| 울트라마린 | 선택, 협동 표시 | #404D73 |
| 양피지 | 글 바탕, 카드 | #D9CFB8 |
| 엄버 | 글자, 그림자 | #3D3024 |
| 대리석 | 배경 | 흰 바탕 + 회색 결 (살짝 누렇게) |

- 빛: 키아로스쿠로 — 화면 가장자리 어둡게(비네트), 중요한 것에만 빛.
- 장식: 아칸서스 잎 소용돌이, 월계관, 카르투슈(둥근 방패꼴 명판), 두루마리 리본. 과하지 않게 — **모서리와 구분선에만**.

## 글꼴
- 제목: 로마 대문자 계열(Trajan 느낌, 무료: Cinzel). 한글 제목: 본명조/Noto Serif KR 굵게.
- 큰 첫 글자(장식 머리글자)는 그림 해설 카드에만.

## 요소
- **버튼**: 금박 테두리 카르투슈, 누르면 금이 살짝 눌림(그림자 안쪽).
- **패널**: 벨벳 바탕 + 금 실선 테두리, 또는 양피지 두루마리(해설·편지).
- **타이머·점수**: 모래시계 + 로마 숫자는 장식용으로만, 실제 숫자는 아라비아 숫자(읽기 쉬움).
- **찾은 표시**(숨은·다른 그림): 금박 원이 그려지며 반짝.
- **협동 플레이어**: 사람마다 문장(紋章) 색 — 울트라마린, 진홍, 녹청, 금.

## 지킬 것
- 명화가 주인공이다. UI 는 그림을 가리지 않게 테두리로 물러난다(게임 중엔 위·아래 얇은 띠만).
- 색약: 협동 색은 모양(문장 무늬)으로도 구분.
