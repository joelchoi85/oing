# 실물 퍼즐 표현

목표: 화면 속 조각이 **손에 잡히는 판지 조각**처럼 보이게. 2D(CanvasItem) 로 하되 빛·두께를 흉내 낸다. 빛은 왼쪽 위에서 — 바로크 명암(키아로스쿠로)과 맞춘다.

## 1. 조각 모양
- 격자를 약간 흔든(지터) 뒤 이웃마다 **탭(볼록)/블랭크(오목)** 를 정한다. 테두리 조각은 그쪽 변이 곧다.
- 탭 모양은 베지어 곡선 6~8개: 목이 좁고 머리가 둥근 고전형. 조각마다 크기·기울기·목 위치를 조금씩 다르게(같은 모양 반복 금지 — 진짜 퍼즐은 거의 같은 모양이 없다).
- 결정론: `퍼즐 = 그림 + 조각 수 + 씨앗(seed)`. 같은 씨앗이면 협동하는 모두가 같은 모양을 만든다 → 네트워크로 모양을 보낼 필요가 없다.
- 판 생성은 노드 없는 `RefCounted` 로(헤드리스 테스트: 조각이 서로 정확히 맞물리는지, 넓이 합 = 그림 넓이).

## 2. 한 조각의 층 (아래 → 위)
1. **그림자**: 조각 모양을 흐리게(가우시안) 한 검은 판, 오른쪽 아래로 2~3px. 들면 6~10px·더 흐리게·더 옅게 + 조각 1.04배 → 떠오름.
2. **옆면(두께)**: 같은 모양을 아래로 2~4px(확대 배율에 비례) 밀어 그린 판. 색은 **판지 결 텍스처**(회갈색, 가는 섬유 무늬, 살짝 얼룩). 오른쪽·아래 옆면만 보인다(빛 방향).
3. **앞면 인쇄**: 그림 조각. 테두리 안쪽 1~2px 에 **베벨 음영** — 왼쪽 위 가장자리는 밝게, 오른쪽 아래는 어둡게(칼로 눌러 자른 둥근 모서리).
4. **표면 질감**: 아주 옅은 종이·광택지 결(무광 코팅). 빛 방향에 따라 반사가 살짝 움직이면 좋음(확대 시).
5. **가장자리 잡티**: 앞면 가장자리에 아주 가는 흰 섬유 보풀 몇 가닥(인쇄가 살짝 벗겨진 자국) — 조각마다 다르게.

## 3. 만드는 법 (Godot)
- 조각 모양 → 다각형(곡선을 잘게 쪼갬) → `Polygon2D` 또는 메시 + 텍스처 좌표 = 원본 그림 좌표.
- 조각마다 **거리장(SDF) 텍스처**를 한 번 만든다(불러올 때, 작은 해상도). 셰이더가 SDF 로:
- 셰이더 노브(파일 맨 위 상수 / uniform): `THICKNESS_PX`, `BEVEL_PX`, `LIGHT_DIR`, `SHADOW_OFFSET`, `LIFT_SCALE`, `SIDE_TINT`.
- 성능: 조각 300개 × 층 3개. 놓인 조각은 판 단위로 한 텍스처에 굽는다(움직이지 않는 덩어리는 그림 한 장). 든 조각만 실시간.

## 4. 붙었을 때
- 맞물린 조각 사이엔 **가는 이음선**(어두운 선 + 한쪽 밝은 선)이 남는다 — 완성해도 "퍼즐"로 보이게.
- 붙는 순간: 착 소리(판지 딸깍) + 이음선을 따라 빛이 한 번 지나감.

## 5. 테이블과 상자
- 배경: 짙은 초록 펠트 또는 어두운 호두나무 탁자(선택). 가장자리는 어둡게(비네트).
- 시작: **퍼즐 상자 뚜껑**이 열리고 조각이 쏟아진다(물리처럼 흩어짐, 일부는 뒤집힌 회색 뒷면 — 옵션 "뒷면 조각": 탭하면 뒤집힘).
- 뒷면: 판지 회갈색 + 희미한 인쇄 번호(진짜 퍼즐처럼).

## 6. 소리
- 판지 조각 집기(사락), 놓기(톡), 맞물림(딸깍), 상자 쏟기(촤르르). 실물 녹음 느낌, 과하지 않게.

## 확인 방법
- 스크린샷을 실물 퍼즐 사진과 나란히 놓고 비교(두께·그림자 거리·베벨 폭).
