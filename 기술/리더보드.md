## 무엇을 겨루나
- **그날의 그림**만: 매일 한 점, 그 그림의 직소(48·150)·숨은 그림·다른 그림 판. 모두 같은 판(같은 씨앗·같은 정답)을 푼다.
- 주간·전체 기록은 그날 판들의 합산이 아니라 **판별 순위**만(비교가 단순해야 납득된다).
- 숨은·다른 그림은 숙련되면 쉬워진다 → 매일 새 그림 + 어려움 구간 판이라 외워서 이길 수 없다. 같은 판 다시 하기는 기록에 안 들어간다(첫 완료만).

## 점수
- 숨은·다른 그림: **시간 + 벌점**(틀린 탭 +3초, 힌트 +15초). 작을수록 좋다. 동점이면 틀린 탭 적은 쪽.
- 직소: 시간. 협동은 팀 기록(인원수별 따로 순위: 1인/2인/3~4인).
- 보여 주기: 내 순위, 상위 10, 내 위아래 5, 친구(초대 코드로 맺은 사람).

## 기록 검증 (서버 비용 작게, 결정론)
- 클라이언트는 결과 숫자만이 아니라 **탭 기록**을 보낸다: `[(시각 ms, x, y), ...]` — 숨은·다른 그림은 판당 수십 개라 작다.
- Worker 가 판의 정답 다각형으로 **다시 채점**한다(점 ∈ 다각형, 같은 벌점 규칙). 클라이언트와 같은 순수 함수(노드 없는 채점기)를 JS 로도 둔다 → 테스트로 둘의 결과가 같은지 확인.
- 직소는 조각 놓기 기록이 커서, 완료 시간 + 놓기 수 + 표본 몇 개만 검사(느슨하게).
- 이름: 닉네임만(계정 없음). 기기마다 무작위 키를 만들어 서명 → 같은 사람 구분. 나쁜 말 필터.
